Run 1: Cold Start (Why Cheap Cheaters Win Bids First, Get Caught, and Get Paid ₹0)

When you start AGENTFLOW freshly (`./scripts/run_all.sh`), the database has zero transaction history. Here is the exact sequence that happens when you click Run Task:

  1. Equal Starting Trust ($R = 0.500$): Every provider starts with `succ=0, fail=0`. Using $\text{Beta}(2,2)$, both honest `CleanCo` and cheating `QuickClean` have Verified Reliability $R = \frac{0+2}{0+0+4} = 0.500$ (even though `QuickClean` claims `0.99` in its marketing manifest).
  2. Price Breaks the Tie on Attempt 1: Because both have $R = 0.500$, `QuickClean` (₹1.00 quote = 105p gross) scores higher than `CleanCo` (₹2.00 quote = 210p gross).
  3. Contract & Escrow Hold: Buyer signs contract `c-1` with `QuickClean` and locks `105 paise` in `escrow:c-1`.
  4. Cheater Delivers Poisoned Data: `QuickClean` runs in `fabricate` mode—it skips deduplication and injects fake 5-star reviews (`id: "fake-0"`).
  5. Verifier Catches It Deterministically: `gateway/verifier.py` compares output IDs against input ground truth (`common/domain.py`), flags `no_fabricated_ids` and `completeness` as `FAIL`, and signs a rejection verdict.
  6. Atomic Refund + Bond Slash + Reputation Drop:
    • `escrow:c-1` refunds `105 paise` back to `user:demo` (User lost ₹0!).
    • `bond:provider-quickclean` is slashed by `100 paise` (₹1.00 penalty moved to `platform:slashed`).
    • `QuickClean` reputation updates to `succ=0, fail=1` → $R = \frac{2}{5} = 0.400$.
  7. Autonomous Retry (Attempt 2): Within the same task, `orchestrator.py` excludes `QuickClean`, re-bids Stage 1 to `CleanCo`, negotiates `CleanCo` down from `200p` to `170p`, verifies `PASS`, releases payment, and upgrades `CleanCo` to $R = \frac{1+2}{1+0+4} = 0.600$!

Run 2: After Learning (Why Run 2 Finishes in Half the Time with 0 Failures)

When you click Run Task a second time on the dashboard without resetting:

  1. Reputation Gap Is Now Established:
    • `CleanCo` Verified $R = 0.600$ (1 verified pass)
    • `QuickClean` Verified $R = 0.400$ (1 verified failure, bond slashed)
  2. Trust Outweighs the Price Gap:
    • Under `Balanced` ($w_R=0.40, w_C=0.40$) or `Auto: High Compliance` ($w_R=0.72$), `CleanCo`'s higher reliability bonus ($+w_R \cdot 0.60$) beats `QuickClean`'s lower score ($+w_R \cdot 0.40$).
  3. Zero Wasted Calls: The Buyer skips `QuickClean`, `BargainSent`, and `CheapReport` on Attempt 1 across all three stages (`clean_data` → `sentiment` → `report`).
  4. Measured Benchmark Proof (`docs/BENCHMARK.md`):
    • Naive (Pay on Delivery): 0% correct reports, ₹4.20 wasted on bad work per task.
    • Cheapest + Verification: 100% correct reports, ₹0 wasted, but suffers 3 bad deliveries every single run (5.6s avg runtime) because it never learns.
    • AGENTFLOW: 100% correct reports, ₹0 wasted, bad deliveries drop from 3 → 0, and runtime drops in half (2.9s)!
